Requests Without Profile

These requests exist but have no corresponding user profile data.

Possible Reasons for Orphaned Records:

  • Setup Bypass: Users might have accessed the request form directly without completing the one-time profile setup.
  • Setup Failure: A network error might have occurred after saving the request but before the profile was saved.
  • Data Deletion: User profiles might have been deleted from the spreadsheet while their connection requests remained.
  • Email Mismatch: Inconsistencies in email formatting (case sensitivity or trailing spaces) between the Requests and Profiles sheets.
  • Manual Entry: Records might have been added directly to the spreadsheet by an administrator.
